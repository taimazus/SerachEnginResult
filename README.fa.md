# ردیاب محلی رتبهٔ جست‌وجو

[English](README.en.md)

یک وب‌اپ محلی برای ثبت چند پروژه، عبارت جست‌وجو و دامنهٔ هدف و نگهداری تاریخچهٔ بررسی رتبه در SQLite. اجرای جست‌وجو فقط با کلیک کاربر انجام می‌شود. راه‌اندازی سریع در Windows در [README](README.md) آمده است.

## فارسی، فونت و وابستگی‌ها

- رابط فارسی راست‌چین است و فونت Vazirmatn را از فایل محلی `static/Vazirmatn.woff2` بارگذاری می‌کند؛ هیچ CDN یا سرویس فونت خارجی لازم نیست.
- متن مجوز فونت در `static/OFL.txt` قرار دارد.
- فایل `run.bat` روی Windows محیط مجازی `.venv` و بسته‌های Python را در کنار پروژه آماده می‌کند و سپس برنامه را اجرا می‌کند. اگر Chrome یا Edge روی سیستم نصب باشد، Playwright از همان مرورگر استفاده می‌کند؛ در غیر این صورت، تلاش می‌کند Chromium را محلی دریافت کند. اگر دریافت مرورگر ناموفق شود، رابط همچنان باز می‌شود، اما بررسی رتبه تا نصب مرورگر قابل اجرا نیست.
- Python نسخهٔ 3.10 یا جدیدتر باید از قبل نصب باشد. فایل BAT در نبود Python راهنمای نصب نشان می‌دهد و خود Python را نصب نمی‌کند.
- مرورگر Chromium در صورت نیاز در `browser-runtime` و بسته‌ها در `.venv` نگهداری می‌شوند؛ این پوشه‌های حجیم محلی هستند و در Git ثبت نمی‌شوند. Chrome/Edge موجود روی سیستم هم می‌تواند جایگزین Chromium شود.

## محدوده و محدودیت‌ها

- بررسی دستی نتایج Google به‌کمک Playwright؛ حداکثر ۵ صفحه برای هر اجرا (پیش‌فرض ۳).
- موقعیت درخواست `gl=ir` و زبان مرورگر `fa-IR` تنظیم شده‌اند؛ این‌ها تضمین‌کنندهٔ رتبهٔ واقعی یا مکان دقیق کاربر نیستند.
- اگر Google صفحهٔ CAPTCHA نشان دهد، اجرا متوقف و رویداد ثبت می‌شود. CAPTCHA دور زده نمی‌شود؛ پراکسی چرخشی، زمان‌بندی خودکار و تقلید برای مخفی‌کردن خودکارسازی وجود ندارد.
- HTML و selectorهای Google ممکن است تغییر کنند؛ نتایج باید به‌عنوان برآورد مشاهده‌شده تلقی شوند، نه تضمین یا دادهٔ رسمی SEO.
- داده‌ها در `rank_tracker.sqlite3` کنار برنامه ذخیره می‌شوند. مسیر جایگزین با متغیر محیطی `RANK_TRACKER_DB` قابل تعیین است.
- برنامه API یا سرویس ابری ندارد. از انتشار آن روی شبکهٔ عمومی خودداری کنید.

## راه‌اندازی در Windows

```powershell
.\run.bat
```

در اولین اجرا فایل BAT بسته‌های برنامه را دریافت می‌کند. اگر Chrome یا Edge نصب باشد، برای مرورگر دانلود جداگانه‌ای لازم نیست؛ در غیر این صورت، BAT تلاش می‌کند Chromium را دریافت کند. اجرای فایل را تا بازشدن صفحهٔ محلی نگه دارید؛ نشانی معمول `http://localhost:8501` است. اگر دریافت مرورگر در دسترس نبود، رابط همچنان باز می‌شود و خطای بررسی رتبه دستور بعدی را نشان می‌دهد.

اگر نسخهٔ قدیمی برنامه هنوز در مرورگر باز است، پنجرهٔ اجرای قبلی را ببندید، `run.bat` را دوباره اجرا کنید و صفحه را تازه‌سازی کنید تا کد جدید بارگذاری شود. خطاهای اجراهای قبلی در تاریخچه باقی می‌مانند، اما به‌صورت پیام خلاصه نمایش داده می‌شوند.

برای نصب دستی:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\browser-runtime"
python -m playwright install chromium
streamlit run app.py --server.address 127.0.0.1
```

## استفاده

1. یک پروژه بسازید.
2. عبارت جست‌وجو و دامنهٔ هدف را اضافه کنید.
3. برای همان عبارت روی «بررسی رتبه» کلیک کنید.
4. نتیجه و حداکثر پنج اجرای اخیر را ببینید.

رتبه بر اساس لینک‌های قابل استخراج از نتایج ارگانیک و URLهای یکتا شمرده می‌شود. تبلیغات و لینک‌های `google.com` شمرده نمی‌شوند. ظاهر و تعداد نتایج Google ممکن است باعث اختلاف با شماره‌گذاری صفحه شود.

## آزمون‌ها

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

آزمون‌ها ذخیره‌سازی SQLite، اعتبارسنجی و تطبیق دامنه را بررسی می‌کنند؛ درخواست واقعی به Google جزو آزمون‌ها نیست.
